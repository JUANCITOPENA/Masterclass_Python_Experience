Bienvenidos al repositorio oficial de la **Masterclass Python Experience PRO**. Este proyecto es una inmersión intensiva diseñada con precisión quirúrgica para llevar a los estudiantes desde los fundamentos hasta la creación de **Agentes de Inteligencia Artificial** empresariales.

## 🚀 ¿Qué es este Proyecto?

Este repositorio contiene la arquitectura interactiva web (`index.html` guiado) de nuestra Masterclass. Está estructurada para transformar el aprendizaje teórico en casos de uso prácticos, orientados al mercado laboral actual.

### 📌 Arsenal de Conocimientos:
1. **Roles y Fundamentos:** Estructura de la industria IT y la ingeniería de software.
2. **Ecosistema Python:** Las entrañas del lenguaje líder mundial.
3. **Arquitectura y Entornos:** Gestión profesional con `.venv`.
4. **Lógica Pura:** Estructuras, algoritmos y resolución de problemas.
5. **Ecosistema Analítico (Data Science):** 
   - **Pandas:** Manipulación y limpieza masiva de datos.
   - **Matplotlib:** Visualización de tendencias y distribuciones matemáticas.
   - **Streamlit:** Transformación de scripts a aplicaciones web instantáneas.
6. **Casos Prácticos (APIs e Integraciones):** 
   - Manipulación avanzada de archivos Excel/CSV.
   - Consumo asíncrono de APIs globales (Clima en tiempo real, Cotización de Divisas, Bitcoin).
7. **👑 Proyecto Cumbre: Agente Analítico de Inteligencia Artificial** 
   - Creación de un Chatbot empresarial con el cerebro de **Google Gemini**.
   - Capacidad de leer bases de datos subidas por el usuario.
   - Motor de *Streaming* de texto, generación de análisis ejecutivos e impresión de **Reportes PDF automáticos** con métricas clave y gráficos.

## ⚙️ Stack Tecnológico Implementado

- **Core:** Python 3.10+
- **Frontend / Portal:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Librerías de Datos & Gráficos:** Pandas, Numpy, Matplotlib, ReportLab
- **Deploy Rápido:** Streamlit
- **Cerebro de IA:** Google GenAI SDK (Modelos Flash 3.8 / 3.6 / 3.1)
- **Ejecución en Navegador:** Pyodide (para los ejercicios interactivos del portal)
